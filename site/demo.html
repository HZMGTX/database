What it is Search Source

Read this first: this is a demo, not the application.

Vault is a database in a file on your disk. Nothing on a serverless host can be that, because the filesystem is thrown away between requests — so what is running here is a read-only copy of the query engine, over 70 synthetic items baked into the page. Every person, client and figure in it is invented. You cannot add, edit or delete anything, and nothing you type leaves your browser.

How much of this is the real engine

The query language, the BM25 ranking and the four column weights are the real ones. Each of the example queries in the rail is executed by the actual Python engine when this page is built, and replayed through the JavaScript by a test that fails if a single item differs — in content or in order.

What is here and not real: the query engine is a reimplementation, so anything outside those checked examples is only as good as the reimplementation. What is missing entirely: the trigram index for substrings and typos, synonym expansion, attachments, and writing anything down.
